# CLI synthetic contract fixture

`mdbx-cli-contract-v1.zip` contains only synthetic credentials. It is generated by
CLI `contract_tests::synthetic_cross_client_fixture_and_portable_copy`, including
unknown/future types, precise numbers, literal serde marker keys, collections,
external attachment blocks, and input-chosen Android return identities.

Archive SHA-256: `e9613006b4f89f59197ddc716791ce0156a15ba260783c43648517e08385eed0`.
Both Android variants use identical bytes. Default instrumentation extracts it
into a unique private cache directory and removes all temporary files afterward.
For fresh fixtures and independent CLI verification, use CLI
`scripts/check_android_contract.py` with the installed test APK. Keep the original
host manifest as the expected-value authority.
