# 1.0.315 后台数据任务验证

日期：2026-10-01。对应未发布版本，不包含提交、标签或发布操作。

## 行为

- 导入导出页面提交的数据任务、手动 WebDAV 全量备份由前台服务持有；返回上页或桌面不会取消任务。交互式选文件、解密密码输入和第三方登录仍需用户完成。
- 通知使用低重要性渠道，显示阶段和可计算的实际进度，无提示音。Android 12 请求立即显示通知；通知未授权时不阻止任务，页面提供通知设置入口。
- 重新进入可查看进度、结果和导入摘要。点击通知仍须经过正常身份验证，通知不包含密码、验证码或条目名称。
- 导入、导出、手动 WebDAV 备份共享一个运行任务，阻止重复提交。已有定时同步保持原有行为，本轮没有新增后台定时同步功能。

## WebDAV 传输

用户日志显示外层 `InterruptedIOException: timeout` 包裹内层 `IOException: Canceled`，此次没有 HTTP 429/503 证据。原实现将备份上传与目录请求共用 15 秒整次请求限制，并一次性读入完整 ZIP。

现在备份文件通过 64 KiB 缓冲区流式传输，单独使用 60 秒读写空闲超时、30 分钟总超时；目录请求保持原有限制。继续复用原有认证、证书确认和服务器限流等待。错误分类保留外层超时，不把真正的主动取消当作超时。上传不自动重试，使用条件创建避免覆盖同名远端文件。

## 数据边界

- 沿用原有备份格式、加密和保留策略，完整备份名称继续匹配既有保留规则。
- 下载写入临时文件，校验完整后替换；中断下载保留原有完整文件。
- 导入失败不删除源文件，不清除数据库或 Keystore。导出失败清理仅限本次输出文件，无法清理时提示用户。
- 敏感参数只存在进程内存；磁盘只保存任务标记，不保存可自动重放的导入请求。
- 系统杀进程、强行停止、重启和厂商后台限制仍可能中断任务。再次打开提示检查数据后决定是否重试，不自动重复导入。已经完成写入的项目可能保留，不能将所有格式的导入描述为整批原子回滚。

## 验证

- 普通版和 F-Droid 均完成 Debug APK 与测试 APK 编译。
- 两版各 22 项相关 JVM 测试通过：超时分类、超过旧 15 秒限制的传输、截断下载保护、取消与限流、同步任务所有权。
- 普通版另通过 13 项备份保留策略测试。
- 普通版公共 API 32 模拟器 6 项设备测试通过：导入返回桌面后继续、重入结果、防重复写入、失败保留原始输入和记录、退出等待后的真实 HTTP 上传、密码重试、导出重入及加密 WebDAV 归档往返。
- F-Droid 同样 6 项设备用例通过：5 项后台任务 / UI 用例在组合运行通过；归档往返在修正隔离测试配置后单独复测通过。HTTP 例外仅作用于测试配置，测试后恢复网络客户端上下文，正式版明文 HTTP 防护不变。
- 已检查两版真实进度和结果页面截图，保存在设计目录的 `android-progress.png`、`android-result.png`。测试过程遇到模拟器锁屏超时及系统服务停滞，接通模拟电源、重启后完成验证；没有将这些失败算作通过。
- 设备测试使用独立测试用户及合成数据，校验安装包哈希；不删除公共 AVD 数据盘或应用数据。
- 本轮未使用用户的真实云端账号，未在其 vivo / Android 16 环境复现；通过本地 HTTP 服务和实际 ZIP 加解密验证传输与恢复链路。
