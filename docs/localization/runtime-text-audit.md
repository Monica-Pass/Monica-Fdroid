# 运行时文案与语言回退

2026-09-15，Android 1.0.311。

`values/legacy_ui_strings.xml` 曾保留抽取前的中文默认值，导致英文及缺少对应译文的语言显示中文。前一轮将默认值统一为英文，并将中文放入 `values-zh`，但一些既有语言仍有大量缺项，会回退到英文。本轮继续补齐每种可选语言的全部项目资源，校正明确的旧译文错误。语言原生名称、产品名与技术标识保留原样。

## 覆盖范围

默认资源共 5,997 项：5,996 个 string 和 1 个 plurals。本轮新增的是 11,989 条缺失译文，不是 11,989 个新资源键。同一资源在不同语言中的补译分别计数。

英文使用默认 `values`。加上英文，共 11 种语言。跟随系统是选择方式，不另算语言包。

补译覆盖所有 XML 模块，包括 Bitwarden 登录、解锁、同步、文件夹与 Send，MDBX 管理、诊断、结构及冲突，KeePass 和云端文件操作，备份恢复、Steam 导入、图片选择、项目移动、自动填充诊断、历史显示、API 令牌及旧版主资源。复核了明确的语境误译、混杂英文、过长标签、技术名称和 Android 分隔符转义。没有修改 Passkey 注册、签名、计数、密钥存储或其他业务流程。

## 维护约定

- Compose 文案使用 `stringResource`。ViewModel、服务及文件源注入 `StringResolver`；`AppLocaleStringResolver` 使用当前应用语言，并缓存资源配置，不保留 Activity。
- 默认文案放入 `values`。新增资源必须同时维护上表中的全部十个语言目录，包括模块文件；不能只补英文或只检查 `strings.xml`。新语言加入 `Language` 后，也须加入完整资源检查和设备语言验证。
- 翻译须结合实际场景和已有术语，按钮与导航优先采用常用短词。不要复制英文来满足覆盖率；产品名、协议、算法、文件名、网址、占位符和语言原生名称除外。
- 2FA 和 Steam 卡片的下一次验证码标记按产品要求固定显示英文 `Next`，由公共 `TotpCodeCard` 直接定义，不随界面语言翻译。
- 保留 printf 参数、具名变量、KeePass Auto-Type 令牌及有意的换行。复数遵循目标语言规则；俄语和波兰语覆盖 one/few/many/other，日语等语言可以只提供 other。需保留的首尾空格用 Android Unicode 转义或正确的引号包裹，避免 AAPT 去掉空白或把引号显示出来。
- 错误文案不能决定同步策略。远端版本冲突使用 `KeePassSourceChangedException`，分类器沿异常原因链识别；旧中文和 HTTP 错误匹配保留用于兼容。
- 备份是否跳过连接凭据用 `BackupReport.connectionCredentialsSkipped` 记录，避免导出期间切换语言后丢失警告。旧报告的文案识别仍兼容。
- 已保存的历史字段名、导入别名、协议字段、用户内容与技术日志不作批量翻译。历史标签和确定的系统状态在显示层读取资源，恢复操作仍使用原始标识。
- Passkey 管理页的提示与相对时间使用语言资源，语言维护不应改变凭据的可用性。

## 回归检查

`LocaleResourceCoverageTest` 读取所有模块，要求每种已注册语言覆盖全部默认可翻译资源，并检查重复键、空值、资源类型、复数形式、printf 参数、具名令牌、换行和翻译残留标记。明确需要本地化的新功能提示另有英文副本检查，品牌名和合法同形词不在其中。`FrenchResourceCoverageTest` 不再豁免 259 个旧 UI 资源；对应的豁免名单已移除。

`DefaultLanguageResourceTest` 防止默认资源重新混入中文，语言原生名称除外。文言文和波兰语的专门检查、操作提示、历史显示、云文件提示、错误分类与备份检查继续保留。

设备检查包括：

- `AllLocalesInstrumentedTest`：所有语言的选择持久化、资源解析、打包后字符串格式化、俄语复数、分隔符及 KeePass 令牌。
- `LocalizedBitwardenUiInstrumentedTest`：对全部 11 种语言检查设置、自托管 TLS、解锁表单和 1.4 倍字体下的设置帮助。
- `LocalizedRuntimeMessagesInstrumentedTest`：所有语言下的长期存活文案解析器、自动填充诊断，以及 AES-GCM 备份跨语言恢复。日语合法的汉字不会被当作中文残留。
- `LanguageSelectionDialogTest`：共享语言弹窗、原生名称、大字体滚动及全部语言选项。

弹窗检查使用仅存在于 Debug 的 `LocaleTestActivity`，在 `attachBaseContext` 中沿用应用的语言解析方式。测试规则先保存语言，再启动 Activity，结束后恢复设置；仅替换 Compose 的 `LocalContext` 不足以验证继承窗口宿主配置的 Dialog / Popup。

云请求单测使用本地 MockWebServer；模拟器中的表单测试使用合成输入。这些不等于真实云服务账户或真实站点的验收。
