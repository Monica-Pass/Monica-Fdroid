# 四类编辑页统一与验证 · 1.0.315

2026-09-30 完成原生接入，仍归入未发布版本。普通版、F-Droid 与两个候选的 11 个任务代码／测试文件已核对 SHA-256 一致。

## 行为

- 以当前新建密码页为基准：经典顶栏与存储选择，独立图标／标题，12dp 留白，连续填充表单，底部添加内容和保存按钮。
- 验证器密钥可直接输入并实时预览，右侧内嵌三点进入可见的高级参数；保留扫码和 URI 导入。按需添加备注、关联信息、OTP 参数。已有非默认参数自动显示。
- 银行卡、证件和账单地址通过统一 sheet 添加普通／敏感字段、备注及各自支持的扩展栏目。旧值自动显示；隐藏／展开只影响 UI，不修改数据库字段。卡面入口紧凑显示，图库、附件、嵌入副本编辑仍沿用原有实现。
- 银行卡常用姓名选择嵌入姓名字段，避免独立按钮打断连续分组圆角。
- 修复原有证件编辑问题：完整姓名与结构化姓名可分别保存，修改备注不会再用结构化姓名覆盖已有完整姓名。
