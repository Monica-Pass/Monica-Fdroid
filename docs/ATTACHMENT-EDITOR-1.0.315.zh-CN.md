# 附件编辑页 M3E 重设计（1.0.315，未发布）

- 文件列表复用 `entryGroupShape`：组首尾24dp圆角、相邻4dp圆角、2dp间距；不再在列表外套大卡片。
- 文件名优先，显示大小/来源/待保存状态；图片、PDF、压缩包及其他文件用对应图标与小底板。删除按钮保留48dp触摸区域。
- 空态简洁呈现“暂无附件”，独立整行添加按钮；处理中显示不定进度并禁用重复添加/删除。
- 错误持续显示在页面中并可关闭，已有附件和失败草稿不会因提示消失而被移除。文件元数据读取失败也转为页面提示。
- 附件子页左右12dp，确认采用勾选图标，标题单行，适配1.5倍字体。其他内容子页顶栏及间距保持原样。
- 共享组件应用于密码及卡片等附件编辑入口；沿用系统 OpenDocument、已有加密上传/删除、软上限确认和草稿保存流程，未改变附件格式或数据库结构。
