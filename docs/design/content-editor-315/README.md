统一使用按需编辑，恢复紧凑单行顶栏；移除独立大标题与账号密码留空说明。标题图标有底色，标题与网址形成一个连续分组，账号与密码另成一组。组首尾为 24dp，内部连接处为 4dp、间隔 2dp；被添加网址、绑定应用等操作隔开的区域各自拥有完整外侧圆角。凭据输入改为填充样式，保持文字选择、光标、键盘及密码显隐行为。

新建不再提供第三方登录，已有 SSO 保留原登录类型、提供商、关联条目与备注，不强行转换为密码。经典编辑入口及其失效字段开关与搜索结果移除，保留账号显示与预设字段设置。

内容按添加顺序排列，底部为独立添加按钮。长按整张内容行直接拖动，不展示拖动把手或上下移按钮；无障碍仍支持移动。点击进入详细编辑，菜单支持编辑与确认删除。删除作用于草稿，保存后生效；现有附件仍使用存储后端的逐项删除流程。详情按保存顺序展示支付卡面、验证器与其他内容。

## 数据兼容

常用支付、联系人与地址沿用 PasswordEntry 字段；补充字段沿用加密自定义字段通道，不改 schema。键为 `monica.content.<section>.<field>`，顺序存入 `monica.content.order`。更新保留字段 ID、保护标记、未知字段与未知顺序项。银行卡不再默认展示冗余品牌和昵称，但已有值保持可编辑、可保存。

此前已完成五种 OTP、真实拖动后保存重开、取消与确认删除、未知字段及保护标记、MDBX/KeePass 原生往返和投影重建验证。本轮两版构建通过；普通版 21 个场景分轮通过，F-Droid 9 项关键场景通过。已检查实际分组圆角、图标底色和大字体截图；记录见 verification.json。未运行历史版本二进制或真实 Bitwarden 云端，不能据此保证所有历史版本编辑时均保留新增元数据。
