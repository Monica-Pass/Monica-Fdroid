## 交互

- 中文复用其他语言的整行长卡片，仅最右侧提供独立的 48dp 展开触区；点击箭头只展开或收起。
- 子选项为简体中文、繁體中文、喵喵语、文言文（华夏）。选择后应用语言、更新卡片名称及设置页摘要，并收起子项。
- 点击中文卡片正文应用当前显示的中文变体；「跟随系统」保持为独立选项。
- 子项使用外侧大圆角、相邻小圆角，展开复用 MonicaExpandableContent；按压反馈限制在卡片与箭头圆形范围内。
- 弹窗水平留白 16dp，内容单层滚动；标题和关闭入口固定，大字体允许标签自然换行。

## 语言资源

| 选项 | Locale | Android 资源目录 |
| --- | --- | --- |
| 简体中文 | zh-Hans-CN | values-zh |
| 繁體中文 | zh-Hant-HK | values-b+zh+Hant |
| 喵喵语 | zh-NY | values-zh-rNY |
| 文言文（华夏） | lzh | values-b+lzh |

繁体中文使用香港书面用语，例如用戶名稱、帳戶、數據庫、檔案、資料夾、設定、搜尋、儲存、電郵、網絡和伺服器。技术名称、占位符与 XML 属性保持不变。

显式选择繁体使用 zh-Hant-HK；Hant 资源也供繁体系统语言匹配。缺失文案按繁体、简体、英文的顺序回退，界面和后台字符串解析使用同一规则。简体显式使用 Hans，切换时比较完整 Locale，避免保留系统的 zh-Hant-CN。猫语与文言文沿用原有语言标识和中文回退。
