# Monica for Android 1.0.315 发行说明（已接入 main／未发布）

- 密码、银行卡、证件、地址与笔记的自定义字段采用统一信息卡；去掉重复边距、阴影和卡片嵌套，保留复制、显隐、大字、二维码/Code 128、分享及 Send。
- 密码详情直接展示已有支付信息生成的银行卡面，展开查看卡号、持卡人、有效期和 CVV，敏感值默认隐藏。
- 密码详情复用验证器页面的验证码卡片，沿用类型格式、隐藏设置与时间偏移；关联验证器缺失时，也读取密码自身保存的加密 OTP。
- 改善大字体、窄屏和长字段的操作布局；大字体卡面保留尾号，HOTP 不再误用即将过期的红色；切换条目或更新秘密内容后重新隐藏。

- 附件编辑卡片的“添加附件”移至底部右侧，标题与文件列表独占完整宽度，避免英文大字体标题被挤成竖排。经典和按需编辑样式共用此改进。

以当前 main 为功能基础，在独立候选重新实现，没有合并旧实验分支。密码沿用单组支付信息和已有 OTP 模型，不增加多银行卡绑定或卡包自定义图片关联；HOTP 展示保存的计数器，不新增计数器写入。验证器新增自定义字段继续暂缓。

本轮已接入本地 main 1.0.315 并通过回归验证，后续改动继续归入本版本。尚未提交、推送或发布。
