## 设计与接入

以当前新建密码页为基准：12dp 横向留白，紧凑顶栏、数据库选择、56dp 独立图标与标题、外侧 24dp／内侧 4dp 连续填充分组、底部“添加内容”和独立保存按钮。使用 Canvas 的 textField、listItem、button、iconButton 和 FAB 现成组件。原生去除填充输入框底线，与密码页一致。

银行卡、证件和账单地址复用卡面编辑器，入口收紧为一行，已有卡面仍显示缩略图。银行卡常用姓名选择在姓名字段内部。添加内容按各类型已有能力展开字段，旧数据非空栏目自动可见；显示状态独立于保存数据，不通过隐藏栏目清空旧值。

验证器密钥直接输入，右侧三点可定位高级参数，验证码预览保留图形倒计时；原有扫码与 URI 导入可达。添加内容提供备注、关联信息及 OTP 参数。遵守现有兼容决策：验证器任意新自定义字段仍暂缓，不更改 TotpData 数据格式。
