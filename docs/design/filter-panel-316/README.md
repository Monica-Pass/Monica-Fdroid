# 密码库紧凑筛选菜单

本地 M3E Canvas 草图：见 canvas-url.txt；可编辑源文件 canvas.json。

- 使用与右上角更多菜单相同的 Material DropdownMenu 开合动画；点击外部或返回关闭。
- 不显示额外“筛选”标题和叉号。
- 数据库默认横向一行滚动，点数据库标题可展开为自动换行，再点收起。
- 与卡包菜单共用460dp高度上限，小屏预留96dp可用空间，内容独立滚动；新建分类/编辑固定在底部，使用有背景的 FilledTonalButton。
- 保留应用缩放、类型筛选和整项拖动。内部填满菜单实际宽度，左右各12dp，避免低DPI重复换算导致提前裁切；数据库标题按压裁剪为12dp圆角。
