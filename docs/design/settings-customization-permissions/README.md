## 验证记录

- 普通版与 F-Droid 的 Debug、AndroidTest 构建通过；各 16 项定向 JVM 测试通过，设备测试分别为 17 项、18 项。
- 复用公共 Android 12 / API 32 模拟器；测试 390dp 常规宽度、320dp 窄屏、浅色与深色、中文与英文、最高两倍字体。
- 普通版额外 6 项横屏设备测试通过，验证短高度下的滚动、开关、权限操作及帮助弹窗。
- 权限操作测试保留两版差异：F-Droid 不包含手机状态权限；普通版的相应入口仍被验证。修正测试清单后另对普通版该用例补测通过。
- 三个开关验证实际持久化并恢复测试前的设置；五个入口、返回、设置搜索定位均通过。
- 验证权限四种状态、有效操作、48dp 按钮、加载时禁用刷新，以及系统设置往返、帮助打开与关闭。
- 文字检查核对实际字形边界、完整行尾、行高和省略号，并人工检查截图；不把 Compose 重建段落容器宽度误判成文字裁剪。
- 帮助改为新操作说明并支持滚动。数据库内容与权限授权状态未作修改；未复制交付安装包，未提交或推送。
- 四目录的本轮源文件一致；其他自定义子页面实现与本轮基线一致。APK 哈希、测试结果与源文件哈希见 [验证记录](verification.json)。
