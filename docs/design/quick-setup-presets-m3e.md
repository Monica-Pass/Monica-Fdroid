## 顺序

欢迎与语言 → 选择预设 → Dock → 页面微调 → 安全与自动填充 → 接入数据 → 完成。

Dock 单独一页，只调整显示页面与顺序。页面微调在下一页，按需展开列表、卡片和配色，仅显示当前启用页面的相关选项。上一步／下一步固定在底部，标题与正文一起滚动，避免大字体压缩操作区域。

## 预设

| 方案 | Dock（末尾均保留设置） | 入口 |
| --- | --- | --- |
| Bitwarden · 预览 | 密码库、Send、生成器 | 密码库概览 |
| Bitwarden · 列表 | 密码库、Send、生成器 | 直接进入条目列表 |
| 验证器专用 | 验证器、Steam | 验证器 |
| 分页管理 | 密码、验证器、卡包、笔记 | 密码 |
| 日常常用 | 密码、验证器、生成器 | 密码 |
| 极简密码 | 密码、生成器 | 密码 |

两种 Bitwarden 布局共用现有 `VAULT_V2`，通过 `vaultOverviewEnabled` 切换概览／列表；布局不与数据库绑定，不会自动连接 Bitwarden。分页类方案关闭密码页聚合显示。验证器沿用现有与 Passkey 共用导航入口的规则，不改变 Passkey 数据或认证行为。

## 交互

- 点选方案只更新预览，点击“使用预设”才一次保存页面开关、顺序和相关布局。保存失败留在原步骤供重试。
- 提供“保留当前布局”；返回预设页默认保留后续微调，只有再次明确选择方案才覆盖布局。
- Dock 直接复用设置页的 `BottomNavConfigRow` 卡片，显示完整页面列表，包括已隐藏的项目。长按手柄拖拽排序，松手后保存；开关控制显示，隐藏项目的位置也会保留。提供无障碍上移／下移动作；至少保留一个内容页，设置固定在末尾。
- Dock 沿用既有底栏设置的独立圆角卡片与 12dp 间距。其他操作分组采用外侧大圆角、相邻小圆角，两侧 12dp 留白；按压不增加白色描边。展开复用 `MonicaExpandableContent`。
- 连接数据库、导入数据与了解 Plus 都可以稍后进行；完成时先保存完成标记，再关闭向导。
