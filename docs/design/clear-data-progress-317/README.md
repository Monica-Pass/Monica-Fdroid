# 清空数据进度

设置 → 清空数据 → 选择类型并验证主密码 → 执行进度 → 完成或失败结果。

- 保留现有确认面板与六类选项；验证期间禁用重复确认。
- 执行时显示当前阶段和已提交的条目数，统计数据与清理生成历史时使用不定进度。
- 不通过延迟、计时器或提前增加计数制造进度；快速任务可以直接显示完成结果。
- 执行中的面板不可通过返回、下滑或点击外部隐藏；完成与失败后可以关闭。
- 失败保留此前已完成数量，不宣称全部成功；重建 Activity 后继续显示同一任务。
- 小屏和大字体允许内容滚动，保留底部系统区域留白。

可编辑草图：[canvas.json](canvas.json)。本地 M3E Canvas 地址与压缩文档链接保存在 [canvas-url.txt](canvas-url.txt)，编辑器使用 `http://127.0.0.1:5186/`。
