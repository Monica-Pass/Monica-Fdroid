## 原生实现与验证

六个子页面均使用现有 MaterialTheme：预览与设置分开，分组行自然增高，排序与字段操作置于底部。
主应用图标选择保留原有图标和语言联动；设置持久化沿用原有接口，没有修改密码库格式。

- 普通版与 F-Droid 的 Debug / AndroidTest 构建通过。
- 公共 Android 32 虚拟机：普通版 19 项、F-Droid 20 项界面测试通过；运行前后校验安装包 SHA-256，见 [验证记录](verification.json)。
- 覆盖真实设置保存、排序按钮与拖动、密码必选约束、开关联动、预设字段新增/编辑/删除与敏感默认值遮挡、弹窗滚动及设置搜索逐项定位。
- 六页检查普通中文、深色英文窄屏 320dp 和双倍字体，检查设置文字布局并保存实际 Compose 渲染截图。预览卡片沿用真实列表允许省略长标题的规则。
- 没有在本轮重新覆盖所有物理机、Android API 或数据库回归；本轮不涉及数据库读取/写入逻辑。
