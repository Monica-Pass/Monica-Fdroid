## 实现和验证

- 外层保留原来的整格点击范围，内层 40dp 圆形承载标准 Material 水波纹。按住选中或未选中按钮都不会出现矩形背景。
- 第六项使用可随文字方向镜像的 Input 图标（箭头进入输入框），继续打开自动填充选择页。撤销状态仍使用 Undo，标签和行为保持一致。
- 修改前设备测试复现圆形外 4,380 个像素变化；修复后分别检查七个按钮，浅色 320dp / 1.5 倍字体与深色 360dp 下，圆形外均无按压颜色变化，圆形内保留高亮。
- 普通版和 F-Droid 各 26 项定向单元测试、11 项键盘 UI 测试通过；包含搜索、来源切换、填写、点击范围和撤销。
- 使用公共 API 32 / x86_64 AVD；测试临时恢复足够宽的视口以覆盖 360dp 和 320dp 两组用例，结束后恢复原 840×2100 覆盖尺寸。Material 水波纹使用 Android 渲染时钟，截图测试显式等待实际按压动画。
- 两版 Debug 应用和测试包构建成功，验证应用与测试 APK 身份；本轮未执行 Release/R8 构建。
- 修复已同步两版本地 main 与对应候选，记入 1.0.315 发行说明和 F-Droid changelog 22。未提交、推送或发布。
