各版五个设备套件均核对相同应用/测试 APK 的 SHA-256，使用已有公共 API 32 / x86_64 AVD。三种打包 ABI 均检查 Rust 加速库和 MDBX 原生库。F-Droid 1.0.315 / versionCode 22 元数据及 6 项发布检查脚本测试通过。没有运行 Release/R8 或远端 CI；Bitwarden 用加密模拟服务验证，不代表真实线上账号验收。

复核曾发现普通独立候选缺少被 Git 忽略的生成 Rust JNI 库：APK 会走 Kotlin 回退。确认 Rust 源码与 main 一致后补齐 main 的同源生成库，并执行强制 JNI 调用验证；F-Droid 原本由 Gradle 从源码生成该库。这是候选打包遗漏，未覆盖或替换 main 的 Rust 源码。
