# 密码内卡包内容填充 · 1.0.316（未发布）

可编辑草图保存在 [canvas.json](canvas.json)，本地打开链接见 [canvas-url.txt](canvas-url.txt)。

- 系统填充选择页与 Monica 键盘复用银行卡、证件、账单地址映射。内嵌候选标题为“所属密码 · 卡片名称”。
- 兼容旧版支付和地址字段。存在同类型副本（包括暂时不可读或新版格式）时不退回过期的旧字段。
- 键盘卡包面板补齐独立账单地址。内嵌副本和地址按字段填写；一行横向滚动，避免顺序猜测或增加高度。
- 普通密码面板不查询副本数据；卡包面板使用不含密码、备注、历史或附件正文的密码投影。候选解析在 IO 线程完成。
- 选择时从数据库重新读取，核对父项目、类型、来源和副本身份。拒绝已删除、已归档、已移动、不可用 MDBX，以及读取期间锁库、切换输入框的填写。
- 不创建新数据库记录，不修改既有数据和备份／同步格式。所有真实表单测试只使用公共模拟器的隔离测试用户及合成数据。

验证已完成：普通版与 F-Droid 在公共 API 32 模拟器的隔离用户中各通过 36 项测试，普通版另通过 32 项 JVM 测试，合计 104 次通过、0 失败、0 跳过。完整记录和源码／安装包 SHA-256 见 [validation.json](validation.json)，日志见 `validation/`。

- 真实系统表单：密码内银行卡（卡号、CVV）、证件（号码、姓名）、账单地址（完整地址、城市、省州、国家、邮编）均填写正确。原生账号密码、WebView 输入事件、选择凭据后 OTP 通知回归通过。
- 数据与键盘：独立账单地址、三种内嵌副本、旧字段、损坏／新版数据保护、最新值读取、跨来源移动、不可用 MDBX、锁库和输入框切换均覆盖；测试确认没有创建重复卡片或改写原字段。
- 性能与界面：普通密码列表不读取大体积卡包数据；320dp、150% 字体、深色下动作保持单行横向滚动，并使用实际 EditText 验证点击填写。
- 实测修复 Android 12 丢弃自定义 Parcelable 请求参数的问题，改用系统类型 Bundle 并测试全字段往返与旧调用兼容；补齐标准城市、省州和国家提示识别。
- 每轮恢复原自动填充服务、输入法、无障碍、屏幕超时和当前用户；没有清除应用数据。本轮启动的公共模拟器已关闭，数据盘与配置保留。

边界：系统填充仍取决于目标应用提供的字段信息。无法可靠识别的表单可用 Monica 键盘逐字段选择。本轮没有修改存储、迁移或备份／同步格式，也没有把这轮测试宣称为所有设备、所有网站的兼容保证。
