# Issue 154 · 常用信息输入建议

日期：2026-10-07。目标版本：普通版与 F-Droid 1.0.318。

[原始需求](https://github.com/Monica-Pass/Monica/issues/154) · [本地 M3E Canvas 设计](../design/common-info-318/README.md)

## 实现

银行名称、分行代码、客服电话、凭据分组标签、网站网址和证件签发机关支持输入建议。独立卡包、项目内嵌银行卡与证件，以及旧版附加字段共用同一套候选提取规则。

非空输入且获得焦点时，从已保存的同类字段提取候选。前缀匹配优先，其次按使用次数排序，最多显示三项；支持包含匹配和大小写无关查询。保留分行代码前导零及 URL 路径大小写。点击仅填写当前字段，光标移至末尾，建议收起；继续输入重新匹配，失焦、空输入和无匹配时隐藏。

候选在后台提取和匹配。仅在需要展示建议时订阅数据库，不为每次按键查询数据库，不保存未提交的输入历史，不发起数据库解锁、同步或网络请求。密码数据使用不含密码列的 Room 投影；银行卡和证件通过现有解密及格式解析器提取明确允许的字段。密码、PIN、卡号和证件号均不属于建议字段。

过滤删除、归档、失去数据库归属及归属冲突的条目。Bitwarden 锁定状态、库目录变化和应用会话锁定会更新或清空候选；损坏的加密值和元数据跳过。只新增只读 DAO 查询，无数据库结构及迁移版本变更。

共 40 项通过，无跳过。普通版及 F-Droid 调试包、x86_64 调试包和设备测试包均构建成功。网址保存测试验证其他网址、用户名和密码原值保持不变。

初次设备测试发现测试菜单选择器不唯一、对无滚动父容器请求滚动，以及软键盘下光标浮层影响截图、旧测试宿主丢失 Compose 内容。修正测试定位，采用系统截图，并让相关旧测试复用支持 Activity 重建的调试宿主；保留原断言，完整重跑通过。系统截图进一步发现靠下字段的建议可能落在键盘下方，随后加入实际可视区域边界断言，将测试宿主设为与正式应用一致的 adjustResize，并让建议滚动响应 IME 高度变化。滚动目标另外预留浮动保存按钮的空间，不增加表单间距；最终截图和键盘、保存按钮边界断言均通过。
