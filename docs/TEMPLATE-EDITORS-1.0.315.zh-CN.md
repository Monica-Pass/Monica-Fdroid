# 新建模板与数据库选择 · 1.0.315（未发布）

Wi-Fi、SSH、API Key、GPG、二维码和 API Token 已接入新的 M3E 表单设计。普通密码编辑器保留现有样式。

## 修复

- Wi-Fi/SSH 从当前 MDBX 或文件夹创建时正确继承目标，选择器也包含 MDBX 和文件夹。
- 创建菜单显示七种类型。跨模板传递当前目标列表，包括多目标及文件夹；双栏入口先关闭旧内嵌编辑器。API Token 仍仅支持原生 MDBX，遵守已有放弃修改确认。
- 修复 API Key 旧回调将分类 ID 当成项目 ID 的问题；新建目标初始化不再随筛选变动重复覆盖用户选择。
- Wi-Fi 编辑保留备注、网址、身份信息及 EAP/BSSID/代理/IP 等已有配置。SSH 保留隐藏的凭据、网址、身份信息和备注。
- 不改变数据库格式。模板切换不负责将尚未保存的异类字段自动转换到另一类型。

## 界面

紧凑顶栏、经典数据库选择区；使用 Material 3 填充输入框、菜单、开关和按钮。连续字段外侧24dp圆角、相邻4dp；二维码的独立标题和正文使用完整24dp圆角，备注与附件等区块去除旧式外套卡片。API Key/GPG 标题简化为“添加/编辑”，类型由模板按钮呈现。

[可编辑 M3E Canvas 与原生截图](design/template-editors-315/README.md)。在线 Canvas 受工具认证限制未预览；真实 Android 渲染已检查。
