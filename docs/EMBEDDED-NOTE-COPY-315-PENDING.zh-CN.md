- 项目内编辑复用完整笔记编辑能力，保留编辑/预览切换、正文、标签、自定义字段、图片和附件，隐藏独立数据库选择。

## 实现与验收要求

1. `NoteData.content/tags/isMarkdown/customFields` 和所有图片/附件均复制；不以正文替换已有备注，也不再只保存 `boundNoteId`。
2. 内嵌图片路径必须改为目标项目自有资产的可恢复引用。不得保留对源 ImageManager 文件、源附件行或源数据库 ID 的依赖。
3. 先准备并校验完整副本，成功才更换当前草稿；任一源图片或附件读取失败，不能默默忽略。
4. 源笔记后续修改、删除、来源数据库移除均不影响已保存副本。
5. 兼容已有 `boundNoteId`：完整复制成功后才能解除引用。来源锁定、不可用或复制失败时保留原内容/原引用并提示，不自动清空。
6. 保存、编辑、取消、移除、多个凭据、多个保存目标、跨库备份恢复均验证，尤其是 Markdown 内嵌图片引用。
