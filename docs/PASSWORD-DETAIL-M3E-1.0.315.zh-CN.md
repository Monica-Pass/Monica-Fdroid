# 密码详情 M3E 与卡片信息堆叠 · 1.0.315（未发布）

密码详情的账号、密码、网站、自定义字段、通行密钥及项目信息使用一致的连续分组样式；备注保留全文选择，密码历史保留显示、复制和删除功能。验证器的实现与样式保持不变，银行卡继续使用原卡面组件。

支付、个人、地址信息只在有内容时组成堆叠。封面复用卡包背板与卡面；多项可展开/收起，单项直接显示。组内沿用原内容排序，整组出现在三类信息原先最靠前的位置。个人与地址卡点击进入完整字段弹层，原有补充字段和保护状态保留。该堆叠仅用于显示，不创建卡包项目、不新增绑定、不写入新存储字段，备份和同步格式不变。

附件采用 Material 3 `HorizontalMultiBrowseCarousel`，保留筛选规则、卡面附件排除、文件别名、点击下载、失败重试、预览、外部打开和保存操作。文件名显示在遮罩之外，适配大字体。缩略图仅读取已下载的本地密文缓存，在内存中解码到最多 768 像素，输入限制为 8 MiB；不预下载远端文件、不额外写出明文缩略图。过大或无法解码的图片显示类型图标，仍可点击原有预览。

## 设计与验证

[可编辑 Canvas 草图与访问说明](design/password-detail-m3e-315/README.md)。在线 Canvas 受已保存的浏览器权限限制，没有绕过，也没有把在线渲染计为已验证。采用本地已有组件文档制作草图，并检查 Android 原生截图。

原生截图：[卡片堆叠](design/password-detail-m3e-315/main-wallet-stack-large.png)、[附件轮播](design/password-detail-m3e-315/main-carousel-large-dark.png)、[字段分组](design/password-detail-m3e-315/main-fields-large-light.png)。

普通版及 F-Droid 均构建成功，各通过 9 项 Android 32 设备测试：真实加密图片缩略图/预览、远端图片不自动下载、轮播滑动/重试入口/忙碌状态/动态列表、字段菜单、堆叠顺序与收起、完整字段弹层、实际密码详情页的个人/地址内容、保护字段重新遮蔽、窄屏大字体复制与菜单。APK 哈希在测试前后核对，使用合成数据，清理本次夹具并保留公共虚拟机。

本次未改动远端传输协议，未把这组 UI 回归描述为新的真实 WebDAV/Bitwarden 服务器验证。
