## 关键证据

- 未知类型：原生通用命令创建命名空间新类型 → Android 密码列表只读投影 → 按需详情读取 → 嵌套 JSON、Unicode、空值与 9007199254740993 大整数完整 → 拒绝普通密码编辑、伪装类型、脱离数据库与误删除 → 独立便携备份回读 → 原生重命名后重复导入保持同一 Room 行与 UUID → 原生删除移除缓存。测试数据完全合成。
- 冲突：两个副本对同一项目分别编辑与删除。通过真实 ViewModel 选择传入删除，再重复提交相反选择；首个选择生效且删除不会从 Room 复活。另一冲突保留本机版本，内容仍在。未解决冲突数最终为零。
- 同步：真实原生乱序父提交、分页历史、CLI 库读写、外部文件并发合并、附件、备份和重开回归通过。JVM 补充跨流状态依赖未到齐时不确认、不跳过游标，依赖到齐后继续；429/503 有界退避，认证/条件写冲突和取消不盲目重试。
- 旧库故障：基线触发原生 `FOREIGN KEY constraint failed`；诊断确认失败事务未改变 checkpoint 与对象内容。正式实现仅将精确错误且 checkpoint 不变的分片保留待依赖，其他流推进后重试。最终真实云回归使用正式 provider，未保留临时诊断实现。
- UI：未知字段默认隐藏并可逐项显示/隐藏；冲突选择先确认，取消不提交，不再显示误导的「仅标记解决」。320dp / 1.3 字体缩放下能操作并滚动到完整提交 ID。快照保留默认结构入口，技术信息按需展开。历史显示完整设备、时间、变更对象与说明，参数可选择复制。截图已检查，修正了截取窗口动画中间帧的问题。

## 已知边界

- 当前打包 FFI 没有冲突双方历史 payload 的受控 disclosure，界面明确提示历史值无法预览；没有假装提供完整内容对比。
- 未知类型当前只读，4 MiB 详情上限。已知类型任意未来字段无损写回、更高 payload 版本自动只读及所有历史 Adapter 的 UUID 写回，是兼容规范中的后续验收要求，不能由本轮结果推断全部完成。
- 原生写入可能规范化 JSON 对象键顺序，校验比较完整语义和值；旧 `updateEntry` 便捷 API 不支持任意扩展类型，测试使用通用写入命令。
- 缓存导入仍复用已有全量原生读取；未知 payload 不会持久化到 Room 密码或自定义字段中。详情读取通过独立授权接口。
- Release 只验证构建；本次设备行为回归运行于 Debug 测试包。未宣称真实 OneDrive 服务或新增 ABI 的设备回归。
- M3E Canvas 网页访问被用户拒绝；保留兼容 Canvas 文档及可编辑链接，没有绕过限制，网页预览未验证。实际 Android 组件截图已验证。
