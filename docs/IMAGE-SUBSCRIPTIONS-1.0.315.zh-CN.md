# 图标与卡面订阅（1.0.315，未发布）

## 评估与范围

中等实现复杂度，复用现有图标导入、卡面裁剪和项目保存流程。对经常自定义图标／卡面的用户收益较高；不需要启用任何订阅也可以继续原来的本地选图。

入口：页面调整自定义 → 图标设置 → 图源订阅。按图标、卡面分组，支持添加、刷新、搜索与取消订阅。密码和验证器的自定义图标，以及银行卡／证件／地址共用的卡面编辑器，都可选用对应订阅。

## 图源格式

支持任意 HTTPS 域名的公开 JSON 图包或 PNG、JPEG、WebP 图片直链。普通网页、需要登录的接口、SVG、ZIP 图包不属于本轮兼容范围。不执行图源里的脚本。

```json
{
  "name": "我的图包",
  "icons": [
    { "name": "示例", "url": "https://example.com/image.png" }
  ]
}
```

列表键支持 icons、images、items；也接受顶层数组。图片名称支持 name/title，地址支持 url/src，列表中也可直接填图片链接字符串。支持相对链接，按订阅最终地址解析。重复地址去重，最多 3000 张图片、50 个订阅。演示中 baiitang/Sakura 的 Fileball/Yuan/tubiao.json 使用 name/description/icons 格式，与此兼容；不默认订阅它、不承诺第三方永久可用。

## 保存与数据安全

- 下载原图后才进入卡面裁剪，支持移动、缩放，确认后使用现有项目附件保存链路。
- 选中的图标复制到现有本地图标目录，卡面通过现有裁剪／附件流程保存。项目不依赖远程 URL 显示。
- 取消订阅只移除素材目录记录，不触及已选图标、卡面、密码、数据库或备份。
- 刷新成功才原子替换目录。下载失败、无效列表和本地订阅文件损坏均不自动重置旧目录。
- 订阅目录是设备本地偏好（noBackupFilesDir），本轮不增加数据库字段或订阅配置同步。选用后的图片继续走已有图标／卡面保存与备份兼容机制；未新增对原本不支持附件的存储后端的支持。
- 图源请求使用独立无账号凭据的客户端；搜索在本机完成，不发送项目名称、账号或密码。网络服务仍能看到通常的网络请求信息。
- 原图有体积限制，使用现有有界解码器，源图缓存最多约 48 MiB；缓存清理只在专用缓存目录操作。
