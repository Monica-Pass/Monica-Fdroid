# 1.0.315 统一新建模板与账单地址

## 实现

Wi-Fi、SSH、API Key 和 GPG 复用密码页的图标／标题、按需内容和保存流程，支持备注、完整卡片／笔记副本、字段、附件和内容排序，详情同步显示；Wi-Fi 扫码位于网络名称下面。嵌入 API Key、API 令牌、SSH 和 GPG 使用完整页面及相同核心表单，保留密钥生成／导入。个人信息与地址合为账单地址，复用卡包完整编辑器；银行卡与账单地址直接复用卡包已有卡叠，点击单卡查看完整详情，不再重复展示支付信息折叠栏。保留旧联系信息、证件扩展、卡面和附件。原生 API 令牌继续使用独立 MDBX payload／元数据，支持备注、自定义字段、内容块和 Emoji 图标；原生令牌的附件及带附件卡片复制尚未接入。

## 存储约定

- API Key 保留 `loginType=API_KEY` 与原 marker／endpoint；密钥仍存于加密 password。GPG 公钥继续 Base64 分片，私钥仍存 password。SSH 保留完整 codec 扩展，导入的独立账号密码不清除。Wi-Fi 只修改 SSID、安全类型和隐藏网络标志，原 EAP／代理／IP／未知 JSON 成员不重建。
- 卡包账单地址继续使用已有 `monica.content.wallet.address` version 1 envelope。旧 CONTACT／ADDRESS 在视图中合为 ADDRESS，首次保存内嵌编辑器才写独立 snapshot，原字段保留。冲突姓名、旧证件字段和未知属性映射为账单地址自定义字段；邮箱／电话完整保留，包括多个值。
- 卡面／附件仍属于父项目；所有字节准备成功后才发布内容。取消内嵌编辑不创建独立数据库项目，不删除源卡片。
- 原生 API 令牌不转换成 PasswordEntry。新增 Emoji 在既有 extras 的 custom_fields 内使用 `monica.icon.emoji`，内容块沿用 `monica.content.block.*` 编码，遵守 64 KiB／128 字段限制。超限阻止保存并保留草稿。附件 owner 尚不支持原生令牌，当前不暴露无实现的入口。

## 验证

普通版与 F-Droid 均完成最终 APK／设备测试包构建；每版 35 项相关单测通过。公共 API 32 模拟器覆盖安装当前构建，每版 54 项设备用例中 53 项通过、1 项手动性能基准按设计跳过。普通版结果按同名用例合并最终复测，不把早期失败算作通过；详见 `unified-template-editor-315-verification.json`。

覆盖 Wi-Fi 当前 MDBX 保存及未知网络字段保留、API Key 密钥首尾空白、GPG 生成保存重开、内容排序与取消、原生 API Token 编辑、现有卡叠打开／翻动／收起、银行卡完整详情和旧联系资料投影。文言文、繁体中文、简体中文、德语在深色大字体下检查标题和真实字段标签；新增内容标签补齐 11 种语言，避免回退英文。

复制链路覆盖本地、KeePass、MDBX：附件实际写入并读取后才发布副本字段；发布时保持已经选定的保存位置，不再受当前列表数据库筛选影响。另验证笔记格式、标签与未知字段、删除源卡后仍能读取副本、重复写入重试、缺失卡面时拒绝不完整复制。

公共 AVD 经授权备份后扩至 12 GiB，保留用户 0／10 和原数据，恢复正常系统启动后测试。两版本测试后数据库完整性均为 `ok`；测试前已有密码及相关数据逐行对比保持不变。详细统计保存在验证 JSON，完整原盘与测试前后数据库备份保留在本机。

## 设计与边界

- [可编辑 M3E Canvas](design/unified-template-editor-315/README.md) 使用现成表单、列表和按钮组件。网站／网址为独立完整圆角。密码详情直接复用卡包 `WalletStackCard`／`WalletStackBrowser`／`WalletStackOverlayHost`，没有新增第二套卡叠实现。已检查真实原生截图；在线 Canvas 因连接器报 `unsupported Codex auth method: apikey` 无法渲染。
- 内嵌技术块使用完整页面及共用核心编辑组件，公共附件和其他内容归父项目；不递归嵌套另一套“添加内容”。原生 API Token 的附件 owner 及带资产卡片复制仍待接入，相关入口隐藏，不宣称与密码模板完全同能力。
- 本次未执行真实 WebDAV／OneDrive 跨设备往返。用户新报 MDBX＋WebDAV 无操作显示未同步，按要求留到这轮编辑器收尾之后排查。
- 所有更改归入 1.0.315 未发布说明；本轮未提交、推送或发布。
