# API Key 保存修复（1.0.315，未发布）

独立新建与密码项目“添加内容”的 API Key 编辑器共用模板校验。旧实现把接口地址当成必须符合 HTTP(S) 格式的网址，导致普通文本、无协议地址和本地主机名阻止保存；嵌入编辑器还把校验失败误报为文件或 256 KiB 大小问题。

现在地址按记录文本保存，不修改或补写协议。标题与密钥的必填规则保留，嵌入编辑器缺少密钥时显示已有本地化的必填提示。打开网页仍使用严格的 HTTP(S) 检查，保存地址不会发起请求。

没有更改数据库结构、加密方式、同步与备份格式、256 KiB 内容上限或损坏内容的只读保护。API Key 与 API 令牌保持不同类型。编辑继续保留既有密钥、OTP、备注、嵌入内容和未知字段。
