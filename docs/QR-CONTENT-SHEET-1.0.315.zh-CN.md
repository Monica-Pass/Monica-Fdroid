## 实现

点击密码项目中的二维码内容卡片，直接在底部弹窗显示二维码，可切换 Code 128 条形码，并通过系统文件选择器保存 PNG。复用现有条码渲染器，码面不使用圆角裁切，保留扫描静区。生成工作放在后台线程。

切换只改变显示方式，不改写原文或动态模板，不更改数据库结构、备份或同步格式。动态模板每次打开读取当前字段；缺失字段、超长内容及不支持的条码字符明确显示原因，不截断数据。Code 128 沿用现有可打印 ASCII、80 字符上限和显示宽度校验；中文等内容可使用二维码。
